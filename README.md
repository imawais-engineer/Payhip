# FlowStack Payhip Storefront Dashboard

A production-ready static landing page and dark SaaS-style dashboard concept for a Payhip digital products storefront by **MASoft Labs**.

## Structure

```text
index.html          # Landing page, dashboard shell, Tailwind config, Payhip-ready markup
src/css/styles.css  # Small reusable custom styles layered on top of Tailwind utilities
src/js/app.js       # Reusable data arrays, component renderers, charts, mobile navigation
```

## Usage

Open `index.html` directly or copy the relevant sections into Payhip custom HTML/CSS/code injection areas where supported. Replace the demo arrays in `src/js/app.js` with Payhip exports, webhook-fed JSON, or API responses.
